# Ghostbars

A make.fun entry for "One Word for Your Wi-Fi": one word describing my Wi-Fi,
aiming to be both the funniest and the most accurate.

`main.ts` (Node 22, standard library only) writes the word to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Ghostbars

Full signal bars on the phone, and nothing loads. The bars are there; the
internet is not.

Run it with `node main.ts`.
